class Gfls.ValidatedStringChunk¶
classmethod new(bytes)¶
Parameters:

bytes (GLib.Bytes) – the chunk data.

Returns:

a new Gfls.ValidatedStringChunk with a reference count of one.

Return type:

Gfls.ValidatedStringChunk

Creates a new chunk.

The format of bytes is important: the data contained in bytes must always be nul-terminated, but this must not be included in the GLib.Bytes length.

Added in version 0.5.

get_bytes()¶
Returns:

the self data.

Return type:

GLib.Bytes

The data contained in the GLib.Bytes is always nul-terminated, but this is not included in the GLib.Bytes length.

Added in version 0.5.

get_valid()¶
Returns:

whether self contains valid data.

Return type:

bool

Semantics:

  • If the chunk data is “valid”, it means that all the characters in it were and are valid.

  • If the chunk data is “invalid”, it means that all the characters in it were initially invalid, but have been validated (e.g., by escaping them).

So, a chunk is either all valid, or all invalid. There can’t be a mix of both. To mix both valid and invalid characters in a string, you need to create several chunks.

Added in version 0.5.
