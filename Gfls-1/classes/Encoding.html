Parameters:

Returns:

an integer according to GLib.CompareFunc.

Return type:

int

A GLib.CompareFunc provided for convenience. When 0 is returned it means that the two encodings are equal according to Gfls.Encoding.equals().

It is useful for example for g_slist_find_custom().

classmethod get_default_candidates()¶
Returns:

the list of default candidate encodings.

Return type:

[Gfls.Encoding]

Gets the list of default candidate encodings to try when loading a file.

This function returns a different list depending on the current locale (i.e., language, country and default encoding). The UTF-8 encoding and the current locale encoding are guaranteed to be present in the returned list.

Note that the returned list doesn’t contain all encodings known by Gfls.Encoding, it is a limited list that contains only the encodings that have the most likelihood to fit for the current locale.

Added in version 0.5.

classmethod try_convert(input_bytes, to_codeset, from_codeset)¶
Parameters:

  • input_bytes (GLib.Bytes) – a GLib.Bytes.

  • to_codeset (str) – destination codeset.

  • from_codeset (str) – source codeset.

Returns:

True if and only if input_bytes can be converted without errors, without invalid characters and without fallback characters.

Return type:

bool

Tries a conversion on input_bytes, discarding the output.

from_codeset and to_codeset must be compatible with iconv, see gfls_iconv_open().

If input_bytes ends with an incomplete multi-byte character, that part is ignored. So input_bytes can be for example the first chunk of a file when loading it.

Added in version 0.4.

equals(enc2)¶
Parameters:

enc2 (Gfls.Encoding or None) – a Gfls.Encoding, or None.

Returns:

whether self and enc2 are equal.

Return type:

bool

Returns whether self and enc2 are equal. It returns True if and only if:

  • Both self and enc2 are None;

  • Or both self and enc2 have a UTF-8 charset (see Gfls.Encoding.is_utf8());

  • Or the charsets are equal according to GLib.ascii_strcasecmp() (because iconv-compatible charsets are case insensitive).

Added in version 0.5.

has_known_charset()¶
Returns:

whether self has a charset known by Gfls.Encoding.

Return type:

bool

Returns True if self has a charset known by Gfls.Encoding. In other words: if self is equal to an encoding returned by Gfls.Encoding.get_all().

When the charset string comes from an untrusted source, it can be desirable to check it.

Added in version 0.5.

is_utf8()¶
Returns:

whether self is a UTF-8 encoding.

Return type:

bool

Returns whether self is a UTF-8 encoding.

If self was created with Gfls.Encoding.new_utf8(), the charset is “UTF-8”. But iconv supports other variants: “UTF8”, “utf-8” and “utf8”. This function returns True for all UTF-8 variants supported by iconv.

Added in version 0.5.

to_string()¶
Returns:

a string representation. Free with GLib.free() when no longer needed.

Return type:

str

Returns the encoding name with the charset in parenthesis, for example “Unicode (UTF-8)”. If the name is unknown, just the charset is returned. The name is translated by gettext.

Added in version 0.5.
