class Foundry.FutureItem(**kwargs)¶
Bases:

GObject.Object

Abstract:

No

Structure:

Foundry.FutureItemClass

A property-notifying wrapper around a [class`Dex`.Future] that resolves to a [class`GObject`.Object].

FoundryFutureItem is useful when a future-backed object needs to be exposed to property expressions or bindings. When the future resolves, [property`Foundry`.FutureItem:item] is notified so expressions can re-read the object from the future result.

Added in version 1.2.
