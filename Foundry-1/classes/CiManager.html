Foundry.CiManagerClass

Project service which aggregates installed continuous integration providers.

The manager loads [class`Foundry`.CiProvider] extensions and routes runs back to the provider which created a pipeline or job.

Added in version 1.2.

list_pipelines()¶
Returns:

a [class`Dex`.Future] that resolves to a [iface`Gio`.ListModel] of [class`Foundry`.CiPipeline] or rejects with error

Return type:

Dex.Future

Lists pipelines from all loaded CI providers.

This is active discovery and may access remote resources. UI consumers should call this only in response to an explicit user action, such as opening a continuous integration panel.

Added in version 1.2.
