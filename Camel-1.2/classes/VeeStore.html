Camel.VeeStoreClass

A store that manages a collection of virtual folders.

Camel.VeeStore is a Camel.Store subclass that manages a list of virtual (Camel.VeeFolder) folders. It handles the store-level operations such as folder creation, renaming, and deletion for virtual folders.

Camel.VeeStore manages the virtual folder list entirely at run-time; the driving application is responsible for creating and initialising the virtual folders within the store on each session start.

Camel.VeeStore also automatically maintains an UNMATCHED virtual folder in the folder listings.
