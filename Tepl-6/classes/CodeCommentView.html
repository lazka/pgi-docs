comment_lines(start_iter, end_iter)¶
Parameters:

  • start_iter (Gtk.TextIter) – a Gtk.TextIter.

  • end_iter (Gtk.TextIter or None) – a Gtk.TextIter, or None to comment only the line at start_iter.

Comments the lines between start_iter and end_iter included.

If end_iter is None, only a single line is commented.

Ensure that code comment is supported before calling this function. See Tepl.CodeCommentView.code_comment_is_supported().

Note that end_iter is always included and its line will be commented, even if it starts the line. In the case where end_iter starts the line, and if start_iter and end_iter are the selection bounds, it is not visible in the Gtk.TextView widget that end_iter is “selected” (the previous line is fully selected, but there are no indications at end_iter per se). You may thus need to adjust end_iter before calling this function, to follow well users’ expectations.

Added in version 6.14.

Tepl.CodeCommentView.props.code_comment_is_supported¶
Name:

code-comment-is-supported

Type:

bool

Default Value:

False

Flags:

READABLE

Whether code comment/uncomment is supported.

This property is True when all these conditions are met:

  • The necessary metadata is available, to know what character or string to insert or remove.

  • The Gtk.TextView :editable property is True.

Added in version 6.14.
