NM.SettingHsr.props.protocol_version¶
Name:

protocol-version

Type:

int

Default Value:

-1

Flags:

READABLE, WRITABLE, EXPLICIT_NOTIFY

Configures the protocol version to be used for the HSR/PRP interface. NM.SettingHsrProtocolVersion.DEFAULT sets the protocol version to the default version for the protocol. NM.SettingHsrProtocolVersion.HSR_2010 sets the protocol version to HSRv0 (IEC 62439-3:2010). NM.SettingHsrProtocolVersion.HSR_2012 sets the protocol version to HSRv1 (IEC 62439-3:2012).

Added in version 1.56.
