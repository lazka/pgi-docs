class Gfls.ByteArray¶
append(data, size)¶
Parameters:

  • data (int or None) – the byte data to be added.

  • size (int) – the number of bytes to add.

Adds the given bytes to the end of self, by doing a copy.

If data is None or if size is 0, it will return immediately.

A write operation - as started with Gfls.ByteArray.begin_write() - must not be ongoing.

Added in version 0.5.

begin_write(n_bytes_to_reserve)¶
Parameters:

n_bytes_to_reserve (int) – the maximum number of bytes that this write operation will support.

Returns:

the buffer position where to begin to write the new bytes, or None on failure.

Return type:

int or None

Begins a new write operation, to add bytes to the end of self.

When a successful write operation is finished, call Gfls.ByteArray.end_write(). If this function returns None, don’t call Gfls.ByteArray.end_write().

Only one write operation at a time is supported.

Be careful and avoid out-of-bounds writes! For a simpler method that copies the bytes, see Gfls.ByteArray.append().

Added in version 0.5.

end_write(n_bytes_written)¶
Parameters:

n_bytes_written (int) – the number of bytes added during this write operation.

Ends a successful write operation that was started with Gfls.ByteArray.begin_write().

n_bytes_written must be less than or equal to n_bytes_to_reserve that was provided at the beginning of this write operation.

After calling this function, you can call again Gfls.ByteArray.begin_write() if you need to write more data to the self.

Added in version 0.5.

free_to_bytes()¶
Returns:

a GLib.Bytes, or None.

Return type:

GLib.Bytes or None

Transfers the data from self into a new immutable GLib.Bytes, and frees self.

If no bytes have been added to self, None is returned.

A nul byte is added at the end, but should not be seen as part of the “real” data. In other words, the data contained in the resulting GLib.Bytes is always nul-terminated, but this is not included in the GLib.Bytes length.

Note that embedded nul bytes can also be present inside the “real” data.

This function ensures that the resulting GLib.Bytes doesn’t consume more memory than necessary.

Added in version 0.5.
