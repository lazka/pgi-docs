class Camel.StoreSearchItem¶

A search item object, as returned by the Camel.StoreSearch.get_items_sync(). It can contain additional values, as requested by the Camel.StoreSearch.set_additional_columns(), which can be obtained by Camel.StoreSearchItem.get_n_additional_values() and Camel.StoreSearchItem.get_additional_value().

Added in version 3.58.

get_additional_value(index)¶
Parameters:

index (int) – an index of the item to get, counting from zero

Returns:

additional read value at index index, or None

Return type:

str or None

Gets value of an additional column of an index index, which should be less than Camel.StoreSearchItem.get_n_additional_values(). The order corresponds to the camel_store_search_get_additional_columns(). Asking for an index which out of bounds returns None. Note the actual read value can be also None.

Added in version 3.58.

get_n_additional_values()¶
Returns:

how many additional column values had been read

Return type:

int

Gets how many additional column values had been read. These are related to the Camel.StoreSearch.set_additional_columns().

Added in version 3.58.
