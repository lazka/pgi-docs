class Gtk.EnumList(**kwargs)¶
Bases:

GObject.Object, Gio.ListModel

Abstract:

No

Structure:

Gtk.EnumListClass

A [iface`Gio`.ListModel] representing values of a given enum.

GtkEnumList contains objects of type [class`Gtk`.EnumListItem].

A simple way to use a GtkEnumList is to populate a [class`Gtk`.DropDown] widget using the short name (or “nick”) of the values of an enumeration type:

``c choices = gtk_drop_down_new (G_LIST_MODEL (gtk_enum_list_new (type)),

gtk_property_expression_new (GTK_TYPE_ENUM_LIST_ITEM,

NULL, “nick”));

``

Added in version 4.24.
