get_address()¶
Returns:

the associated GNOME Online Account’s Address

Return type:

str or None

Returns the original Address of the GNOME Online Account associated with the EDataServer.Source to which self belongs. Can be None or an empty string when not filled.

set_account_id(account_id)¶
