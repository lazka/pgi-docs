class v_sim.Dump(**kwargs)¶
Bases:

v_sim.FileFormat

Abstract:

No

Structure:

v_sim.DumpClass

This structure is used to store a dumping extension. Such an extension is characterized by its v_sim.FileFormat and a method that can write a file from the current rendered data.
