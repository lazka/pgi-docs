class Gio.InetSocketAddress(**kwargs)¶

Gio.SocketAddress

Abstract:

No

Structure:

Gio.InetSocketAddressClass

An IPv4 or IPv6 socket address. That is, the combination of a [class`Gio`.InetAddress] and a port number.

In UNIX terms, GInetSocketAddress corresponds to a struct sockaddr_in or struct sockaddr_in6).

Return type:

Gio.SocketAddress or None

Creates a new Gio.InetSocketAddress for address and port.

If address is an IPv6 address, it can also contain a scope ID (separated from the address by a %). Note that currently this behavior is platform specific. This may change in a future release.

New in version 2.40.
