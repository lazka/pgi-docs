addVertices(vertices, prec, shade, alpha)¶
Parameters:

  • vertices ([float]) – a data buffer.

  • prec (float) – a refining precision, between 0 and 100.

  • shade (v_sim.Shade) – a v_sim.Shade structure.

  • alpha (bool) – a boolean.

Transfer vertices representing self into vertices. They are packed using the v_sim.GlExtPackingModels.RGBA_XYZ scheme, using shade to defined the vertice colours depending on the map value. If alpha is True, a fade to 0 is added depending on the map values.

compute_sync()¶

For later use. Currently computation of maps is always synchronous.

New in version 3.8.

export(shade, rgb, precision, filename, format)¶
Parameters:

  • shade (v_sim.Shade) – a v_sim.Shade object.

  • rgb (float) – a colour (can be None).

  • precision (float) – a pourcentage for rendering quality.

  • filename (str) – the location to export to.

  • format (v_sim.MapExportFormat) – the kind of format.

Raises:

GLib.Error

Returns:

True if no error.

Return type:

bool

Export the given map to the format, using the shade color. If rgb is provided and self has some isolines, they will be drawn with this colour, otherwise an inverse colour is used.
