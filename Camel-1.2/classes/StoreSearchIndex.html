class Camel.StoreSearchIndex¶

A structure with search result indexes, holding references to matching records using the Camel.Store, folder ID and message UID triple. Items can be added to the index with Camel.StoreSearchIndex.add() and checked its existence with Camel.StoreSearchIndex.contains().

Added in version 3.58.

Returns:

a new Camel.StoreSearchIndex

Return type:

Camel.StoreSearchIndex

Creates a new Camel.StoreSearchIndex. Free it with Camel.StoreSearchIndex.unref(), when no longer needed.

Added in version 3.58.

add(store, folder_id, uid)¶
Parameters:

  • store (Camel.Store) – a Camel.Store

  • folder_id (int) – a folder ID, other than zero

  • uid (str) – a message UID

Adds a message identified by the store, folder_id and uid into the index self. It can be asked whether the self contains the message with Camel.StoreSearchIndex.contains(). Note the store is not referenced, it’s compared pointer-wise. See Camel.StoreSearchIndex.contains() for more information.

Added in version 3.58.

apply_match_threads(items, kind, flags, cancellable)¶
Parameters:

  • items ([Camel.StoreSearchThreadItem]) – all items used for thread creation

  • kind (Camel.MatchThreadsKind) – one of Camel.MatchThreadsKind

  • flags (Camel.FolderThreadFlags) – a bit-or of Camel.FolderThreadFlags

  • cancellable (Gio.Cancellable or None) – a Gio.Cancellable, or None

Constructs the inout_threads from the items according to the flags and then changes the content of the self to contain only references to messages which satisfy the kind. When there are no items or the kind is Camel.MatchThreadsKind.NONE, the function does nothing.

Added in version 3.58.

contains(store, folder_id, uid)¶
Parameters:

  • store (Camel.Store) – a Camel.Store

  • folder_id (int) – a folder ID, other than zero

  • uid (str) – a message UID

Returns:

True when the message reference is included in the index self

Return type:

bool

Checks whether a message identified by the store, folder_id and uid is included in the index self.

Note the store is not referenced, it’s compared pointer-wise, thus when a different instance of the same service as the one used in the Camel.StoreSearchIndex.add() is used here, the message reference will not be found.

Added in version 3.58.

move_from_existing(src)¶
Parameters:

src (Camel.StoreSearchIndex) – a Camel.StoreSearchIndex, to move items from

Moves all items from the src index into the self. The self and the src can be the same, in which case the function does nothing. At the end of the function the src will contain no items, but it is not freed.

Added in version 3.58.

remove(store, folder_id, uid)¶
Parameters:

  • store (Camel.Store) – a Camel.Store

  • folder_id (int) – a folder ID, other than zero

  • uid (str) – a message UID

Returns:

whether the message existed and had been removed

Return type:

bool

Removes a message identified by the store, folder_id and uid from the index self. Note the store is not referenced, it’s compared pointer-wise. See Camel.StoreSearchIndex.add() for more information.

Added in version 3.58.

unref()¶

Removes one reference on the self. When the reference count drops to zero, the self is freed.

Added in version 3.58.
