Snapd.ChangeClass

Snapd.Change contains information on a current Snap transaction.

Added in version 1.5.

Returns:

a Snapd.ChangeData object with all the data, or None if the field isn’t defined

Return type:

Snapd.ChangeData

Get the data field for this change.
