class Phosh.ShellStateFlags(value)¶

Bases: GLib.Flags

These flags are used to keep track of the state the Phosh.Shell is in.

NONE = 0¶

No other state

MODAL_SYSTEM_PROMPT = 1¶

any modal prompt shown

OVERVIEW = 16¶

overview unfolded from bottom bar

BLANKED = 2¶

primary display off

LOCKED = 4¶

displays locked

SETTINGS = 8¶

settings menu unfolded from top bar
