class Camel.AsyncClosure¶

Run asynchronous functions synchronously.

Camel.AsyncClosure provides a simple way to run an asynchronous function synchronously without blocking the current thread.

  1. Create a Camel.AsyncClosure with camel_async_closure_new().

2) Call the asynchronous function passing camel_async_closure_callback() as the Gio.AsyncReadyCallback argument and the Camel.AsyncClosure as the data argument.

  1. Call camel_async_closure_wait() and collect the Gio.AsyncResult.

4) Call the corresponding asynchronous “finish” function, passing the Gio.AsyncResult returned by camel_async_closure_wait().

5) If needed, repeat steps 2-4 for additional asynchronous functions using the same Camel.AsyncClosure.

  1. Finally, free the Camel.AsyncClosure with camel_async_closure_free().

Added in version 3.12.
