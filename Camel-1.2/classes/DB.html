Parameters:

reader_lock()¶

Acquires a reader lock on the self. It can be called multiple times. Call pair function Camel.DB.reader_unlock() to release it. it’s okay to call this function when a writer lock is already acquired by the calling thread.

Added in version 3.58.

reader_unlock()¶

Releases a reader lock on the self previously acquired by calling Camel.DB.reader_lock().

Added in version 3.58.

Added in version 2.24.

writer_lock()¶

Acquires a writer lock on the self. It can be called multiple times. Call pair function Camel.DB.writer_unlock() to release it.

Note: This adds a transaction on the DB. Not all statements can be executed in the transaction.

Added in version 3.58.

writer_unlock()¶

Releases a write lock on the self previously acquired by calling Camel.DB.writer_lock().

Added in version 3.58.
