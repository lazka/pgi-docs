Added in version 0.10.

do_parse(uri, bytes, playlist, cancellable) virtual¶
Parameters:

  • uri (GLib.Uri) – a source GLib.Uri

  • bytes (GLib.Bytes) – a GLib.Bytes

  • playlist (Gio.ListStore) – a Gio.ListStore for media items

  • cancellable (Gio.Cancellable) – a Gio.Cancellable object

Returns:

whether parsing was successful.

Return type:

bool

Parse bytes and fill playlist with [class`Clapper`.MediaItem] objects.

If implementation returns False, whole playlist content will be discarded.

Added in version 0.10.
