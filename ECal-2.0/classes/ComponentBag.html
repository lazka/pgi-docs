add(client, comp)¶
Parameters:

  • client (ECal.Client) – an ECal.Client

  • comp (ECal.Component) – an ECal.Component

Adds a component into the bag. It’s possible to add the same component from the same client multiple times, in which case any previous occurrence is removed.

The component is identified by the client and its uid/rid.

Note this unsets any previously set user data on the item by the ECal.ComponentBag.add_with_user_data().

Added in version 3.58.

add_with_user_data(client, comp, user_data, copy_user_data, free_user_data)¶
Parameters:

  • client (ECal.Client) – an ECal.Client

  • comp (ECal.Component) – an ECal.Component

  • user_data (object or None) – custom user data, or None

  • copy_user_data (GObject.BoxedCopyFunc or None) – a copy function for the user_data, or None

  • free_user_data (GObject.BoxedFreeFunc or None) – a free function for the user_data, or None

Adds a component into the bag. It’s possible to add the same component from the same client multiple times, in which case any previous occurrence is removed.

The component is identified by the client and its uid/rid.

The function also sets the user data member of a newly created ECal.ComponentBagItem. The user_data is replaced in an existing item only if it’s set (non-None), otherwise it’s left unchanged. See ECal.ComponentBagItem.set_user_data() for more information.

Added in version 3.58.

clear()¶

Removes all components from the bag.

This does not emit the ECal.ComponentBag ::removed for each span, but it notifies about a change in the ECal.ComponentBag :n-spans and in the ECal.ComponentBag :n-items properties, which will be zero.

Added in version 3.58.

dup_item(client, uid, rid)¶
Parameters:

  • client (ECal.Client) – an ECal.Client

  • uid (str) – a component UID

  • rid (str or None) – a component recurrence ID, or None

Returns:

an ECal.ComponentBagItem copy of a stored item, or None when not found

Return type:

ECal.ComponentBagItem or None

Looks up for an item identified by the client, uid and optionally rid, and returns a copy of it. Free the returned item with ECal.ComponentBagItem.free(), when no longer needed

This is a thread safe variant of the ECal.ComponentBag.get_item().

Added in version 3.58.

ECal.ComponentBagItem or None

Looks up for an item identified by the client, uid and optionally rid, and returns it.

This is a not thread safe, it’s valid until the next change of it is received by the self. If thread safety is required, use the ECal.ComponentBag.dup_item() instead.

get_span(index)¶
Parameters:

index (int) – span index, counting from 0

Returns:

an array of ECal.ComponentBag in the index span, or None when the index is out of bounds

Return type:

[ECal.ComponentBagItem] or None

Peeks a current span content. The index should be between 0 and one less than ECal.ComponentBag.get_n_spans().

Unlike the ECal.ComponentBag.list(), the returned array is owned by the self and is valid until the next content change (addition, removal, clear) of the self is done.

If thread safety is required, use ECal.ComponentBag.dup_span() instead.

Added in version 3.58.

list()¶
Returns:

a GLib.PtrArray containing all the currently stored components in the bag as ECal.ComponentBagItem objects.

Return type:

[ECal.ComponentBagItem]

Lists all components stored in the self. The items are of the ECal.ComponentBagItem type. Even only the container is needed to be freed, the items are owned by the container and can be modified in any way without influencing the self.

Added in version 3.58.

lock()¶

Locks the self, to prevent changes from other threads. It can be called multiple times, only each call needs its pair call of the ECal.ComponentBag.unlock().

Added in version 3.58.

Added in version 3.58.

set_min_duration_minutes(value)¶
Parameters:

value (int) – a value to set

Sets minimum duration to be used for the components, in minutes. When the component duration is less than this value, it is increased to it. The default value is 0.

Changing the value does not influence already added components. Use ECal.ComponentBag.rebuild() to rebuild the content.

Added in version 3.58.

ECal.ComponentBag.signals.item_changed(component_bag, item)¶
Signal Name:

item-changed

Flags:

RUN_LAST, ACTION

Parameters:

  • component_bag (ECal.ComponentBag) – The object which received the signal

  • item (ECal.ComponentBagItem) – an ECal.ComponentBagItem

A signal emitted whenever an existing item in the bag is changed. It’s a complement signal for the ECal.ComponentBag ::added signal, in a sense that when adding an item to the bag either the added or the item-changed is emitted, if the component changed.

The item can be modified, but if any properties related to the layout changes then the content needs to be recalculated, for example by calling ECal.ComponentBag.rebuild().

Added in version 3.58.
