Foundry.CiRunOptionsClass

Provider-independent options for local CI execution.

A provider reads a stable snapshot of these values when [method`Foundry`.CiProvider.run] or [method`Foundry`.CiProvider.run_shell] is called. File descriptors are borrowed; the caller must keep them open until the resulting [class`Foundry`.CiRun] completes.

Added in version 1.2.
