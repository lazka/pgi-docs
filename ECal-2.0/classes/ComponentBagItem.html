classmethod equal_by_comp(item1, item2)¶
Parameters:

  • item1 (object or None) – the first ECal.ComponentBagItem

  • item2 (object or None) – the second ECal.ComponentBagItem

Returns:

whether the item1 and item2 are equal regarding the component reference stored in them

Return type:

bool

Returns whether the item1 and item2 are equal regarding the component reference stored in them. Only the client, uid and rid members of the items are used here.

See: ECal.ComponentBagItem.hash_by_comp()

Added in version 3.58.

classmethod hash_by_comp(self)¶
Parameters:

self (object or None) – an ECal.ComponentBagItem

Returns:

hash value for the self's component

Return type:

int

Calculates hash of the self, considering only the client, uid and rid from the self, because the client with the component ID and the recurrence ID uniquely identify the component.

See: ECal.ComponentBagItem.equal_by_comp()

Added in version 3.58.

classmethod new(client, comp, min_duration_minutes, timezone)¶
Parameters:

  • client (ECal.Client) – an ECal.Client

  • comp (ECal.Component) – an ECal.Component

  • min_duration_minutes (int) – minimum duration, in minutes

  • timezone (ICalGLib.Timezone or None) – an ICalGLib.Timezone to calculate the start time for, or None

Returns:

a new ECal.ComponentBagItem

Return type:

ECal.ComponentBagItem

Creates a new ECal.ComponentBagItem, which will have prefilled all members except of those for the user data.

The min_duration_minutes is used to define the minimum duration, in minutes, the item should have set. Any smaller duration is increased to it.

The span_index member is always zero here.

When the timezone is None, the UTC is assumed.

Added in version 3.58.

copy()¶
Returns:

a new copy of the self

Return type:

ECal.ComponentBagItem

Creates an independent copy of the self. If there is set a copy_user_data, then also the user_data member is copied using this function, otherwise the user_data member is just carried over to the new copy.

Added in version 3.58.

free()¶

Frees the self. Does nothing when it’s None.

Added in version 3.58.

read_times(min_duration_minutes, timezone)¶
Parameters:

  • min_duration_minutes (int) – minimum duration, in minutes

  • timezone (ICalGLib.Timezone or None) – an ICalGLib.Timezone to calculate the start time for, or None

Returns:

True when any of the stored times changed, False if not

Return type:

bool

Reads the start time and the duration from the set component, returning whether any of it changed.

The min_duration_minutes is used to define the minimum duration, in minutes, the item should have set. Any smaller duration is increased to it.

Added in version 3.58.

set_user_data(user_data, copy_user_data, free_user_data)¶
Parameters:

  • user_data (object or None) – custom user data, or None

  • copy_user_data (GObject.BoxedCopyFunc or None) – a copy function for the user_data, or None

  • free_user_data (GObject.BoxedFreeFunc or None) – a free function for the user_data, or None

Sets the user data members of the self in a safe way, meaning the function does not change the user data when it’s the same as that already set; otherwise it frees the current user data, if the free function was previously provided, and the assigns the three members to the self.

The function assumes owner ship of the user_data, optionally calling the free_user_data if provided, when the user_data instance is the same as the already set.

Added in version 3.58.
