Soup.CompressionDictionaryRequestClass

Represents a pending request for a compression dictionary.

An instance is emitted with the [signal`Message`:py:func:::request-compression-dictionary<Soup.CompressionDictionaryRequest.signals.request_compression_dictionary>] signal. The handler should either call [method`CompressionDictionaryRequest`.set_dictionary] (synchronously or after ref-ing the object and completing asynchronously) or call [method`CompressionDictionaryRequest`.cancel], then return True. Return False to let other signal handlers run; if no handler returns True the request is treated as cancelled.

Added in version 3.8.

cancel()¶

Cancels a pending [signal`Message`:py:func:::request-compression-dictionary<Soup.CompressionDictionaryRequest.signals.request_compression_dictionary>] request, causing the response to fail.

This can be called synchronously inside the signal handler or asynchronously after ref-ing self and returning True from the handler.

Added in version 3.8.

Provides the dictionary bytes for a pending [signal`Message`:py:func:::request-compression-dictionary<Soup.CompressionDictionaryRequest.signals.request_compression_dictionary>] request.

This can be called synchronously inside the signal handler or asynchronously after ref-ing self and returning True from the handler.
