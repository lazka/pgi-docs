Camel.StoreSearchClass

Search between multiple folders of one Camel.Store.

The Camel.StoreSearch allows to search between multiple folders of a single Camel.Store. It’s primarily meant to be used by the search folders (Camel.VeeFolder), but it can be used without it too.

It can run only one search at a time, using Camel.StoreSearch.rebuild_sync().

The Camel.StoreSearch is not thread safe, it’s meant to be created, used and freed from within the same thread only.

Added in version 3.58.

add_folder(folder)¶
Parameters:

folder (Camel.Folder) – a Camel.Folder

Adds the folder to the list of the folders to be searched in by the self. The function does nothing when the folder is already Camel.part of the folder.

The content is not updated automatically, call Camel.StoreSearch.rebuild_sync() to rebuild the content.

It’s an error to try to add a folder which is not owned by the Camel.Store the self was created with.

Added in version 3.58.

add_match_index(index)¶
Parameters:

index (Camel.StoreSearchIndex) – a Camel.StoreSearchIndex to add

Adds a match index index into the self. It can be referenced in the search expression with ‘in-match-index “index_key”’ statement, where the index_key is “%p” of the index.

The self adds its own reference on the index.

Added in version 3.58.

get_match_threads_kind()¶
Returns:

one of the Camel.MatchThreadsKind constants, referencing the requested match-threads search

out_flags:

bit-or of Camel.FolderThreadFlags

Return type:

(Camel.MatchThreadsKind, out_flags: Camel.FolderThreadFlags)

Gets the kind of the ‘match-threads’ search statement of the expression as recognized by the last Camel.StoreSearch.rebuild_sync() call, as one of the Camel.MatchThreadsKind values.

When it’s other than Camel.MatchThreadsKind.NONE, the caller should gather thread-related data with Camel.StoreSearch.add_match_threads_items_sync(), after which the caller filters the output to a Camel.StoreSearchIndex, which can be set back with the Camel.StoreSearch.set_result_index().

Added in version 3.58.

set_additional_columns(colnames)¶
Parameters:

colnames ([str] or None) – column names, or None to unset

Sets what additional column names should be pre-read and provided in the Camel.StoreSearch.get_items_sync() result. An empty array is the same as passing None for the colnames.

Make sure to call Camel.StoreSearch.rebuild_sync() to have the values read.

set_expression(expression)¶
Parameters:

expression (str or None) – a search expression, or None

Sets the search expression to be used to search the messages in the selected folders with.

The expression can be None, to not search the folders.

The content is not updated automatically, call Camel.StoreSearch.rebuild_sync() to rebuild the content.
