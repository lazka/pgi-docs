get_stack()¶
Returns:

the Gtk.Stack of self.

Return type:

Gtk.Stack

Gets the Gtk.Stack of self.

The Gtk.Stack is exposed in the public API because it is useful for creating a Gtk.StackSwitcher.

If you need to alter the Tepl.PanelStack content, you must use Tepl.PanelStack.get_panel_simple() instead.

Added in version 6.11.
