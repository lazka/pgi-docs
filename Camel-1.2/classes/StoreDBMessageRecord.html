class Camel.StoreDBMessageRecord¶

A message record, with values stored in a Camel.StoreDB.

Added in version 3.58.

clear()¶

Frees dynamically allocated data in the self, but not the self itself, and sets all members to zeros or equivalent. Does nothing when self is None. It can be called on the structure passed to the Camel.StoreDB.read_message().

Added in version 3.58.
