The Qmi.ClientImsdcm structure contains private data and should only be accessed using the provided API.

pdp_activate_request(input, timeout, cancellable, callback, *user_data)¶
Parameters:

  • input (Qmi.MessageImsdcmPdpActivateRequestInput) – a Qmi.MessageImsdcmPdpActivateRequestInput.

  • timeout (int) – maximum time to wait for the method to complete, in seconds.

  • cancellable (Gio.Cancellable or None) – a Gio.Cancellable or None.

  • callback (Gio.AsyncReadyCallback or None) – a Gio.AsyncReadyCallback to call when the request is satisfied.

  • user_data (object or None) – user data to pass to callback.

Asynchronously sends a PDP Activate Request request to the device.

When the operation is finished, callback will be invoked in the thread-default main loop of the thread you are calling this method from.

You can then call Qmi.ClientImsdcm.pdp_activate_request_finish() to get the result of the operation.

New in version 1.37.
